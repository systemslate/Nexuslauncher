# User guide screenshots

`NEXUS_USER_GUIDE.html` loads one image per illustrated figure from this folder.
A slot whose file is missing shows a dashed **Screenshot coming** frame instead, so a
capture can be added at any time: drop the file in with the exact name below and
reload the page. No HTML edit, no build step. Every figure in the guide works this
way — there are no drawn illustrations.

## How to capture

- **Dark theme.** The six captures already in place are dark; a light screenshot
  will look out of place next to them.
- **Portrait, phone screen only.** No device frame, no desk photo. The existing files
  are 575 × 1280; anything from 575 px wide upwards works, and extra resolution helps
  the printed PDF. Keep the status bar — it is part of the real screen.
- **No personal data.** Use demo apps and generic notification text; nothing with your
  own name, e-mail, phone number or messages.
- **Format.** JPEG, quality around 82, or PNG if the screen is mostly flat colour.
  The file name must match the table exactly — it is case-sensitive on a web server.
- **Replacing a file.** Overwrite it; the page picks up the new image on reload.

The printed PDF only includes screenshots that exist at the time it is generated.
